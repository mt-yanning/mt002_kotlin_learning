# First Steps With Kotlin

We begin at the traditional starting point: a simple ["Hello World"][hello]
program.

After that, we consider how to manage more complex applications using the
[Kotlin Toolchain][ktc] and the [Gradle][grad] build system.

After completing this section, you will have seen a few small examples of
Kotlin code, and you will have a solid understanding of how to build and
run Kotlin applications. Other activities such as testing are covered later.
