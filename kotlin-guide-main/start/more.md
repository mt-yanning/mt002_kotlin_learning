# Learning More

This programming guide should give you a solid grounding in Kotlin, but to
attain a high level of proficiency you will need to supplement this material
with other resources. Here are some suggestions for where you can go to learn
more about the language and some of the tools and libraries mentioned in
this guide.

## Official Docs

- [Kotlin docs home page](https://kotlinlang.org/docs/home.html)
- [Kotlin API reference](https://kotlinlang.org/docs/api-references.html)
- [Kotlin Toolchain](https://kotlin-toolchain.org/)
- [Kotest testing framework](https://kotest.io/)
- IntelliJ IDEA [Quick-start Guide](https://lp.jetbrains.com/intellij-idea-getting-started/) & [Help](https://www.jetbrains.com/help/idea/getting-started.html)

## Books

- Aigner, Elizarov, Isakova & Jemerov, [*Kotlin in Action (2nd ed.)*](https://www.manning.com/books/kotlin-in-action-second-edition), Manning, 2024
- Eckel & Isakova, [*Atomic Kotlin*](https://leanpub.com/AtomicKotlin), Leanpub, 2021
- Leeds, [*Kotlin: An Illustrated Guide*](https://typealias.com/start/), TypeAlias Studios, 2025
- Soshin, [*Kotlin Design Patterns & Best Practices (3rd ed.)*](https://www.packtpub.com/en-us/product/kotlin-design-patterns-and-best-practices-9781805121602), Packt, 2024
