# Using This Guide

This guide is an extended tutorial on object-oriented programming in Kotlin,
introducing you to the most important features of the language. It includes
many small programming tasks that explain how the language works and
illustrate its features.

**To gain a solid understanding of Kotlin, you will need to work through
_all_ sections of this guide and complete the majority of the tasks.**
We expect you do to this using the timetabled lab sessions _and_ private study
time.

Note that these tasks do not form part of your portfolio. The portfolio
assignments are separate. You will nevertheless need to do the tasks in order
to gain the understanding needed to complete the portfolio and work on
your projects in Semester 2.

You should be spending 10&ndash;12 hours per week on all of this.
