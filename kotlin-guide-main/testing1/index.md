# Unit Testing (Part 1)

Unit testing is a critical part of software development, and we will expect
you to write good unit tests for much of the code that you submit in
COMP2850.

In this section, we will position unit testing in the context of all
testing approaches, then consider some of the key concepts involved in
writing unit tests. After that, we will introduce you to how unit testing
frameworks can be used to write tests for Kotlin code.

After completing this section, you will understand the basic principles of
unit testing and you will be able to write simple unit tests for functions
using Kotlin's built-in testing library and the [Kotest][kot] framework.

[Part 2][pt2] will cover testing of classes, explore Kotest more deeply and
consider more advanced topics such as test fixtures, mocking and
test-driven development.
