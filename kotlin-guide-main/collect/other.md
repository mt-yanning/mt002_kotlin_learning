# Other Operations

## Properties & Methods

Arrays, lists, sets and maps all have a `size` property that tells you
how many elements are in a collection. In the case of maps, size is the
number of key-value pairs held in the map.

Lists, sets and maps all have an `isEmpty()` method that returns `true` if
collection size is zero, `false` if it is non-zero.

Lists have `indexOf()` and `lastIndexOf()` methods that can be used to
find the first and last occurrence of a particular value in the list. These
will return the index of the value you seek, or `-1` if it couldn't be found.

## Extension Functions

Much of the useful functionality of collections is provided via extension
functions. Many of these functions rely on lambda expressions to maximize
their flexibility, so we will defer discussion of those until [we cover
that topic][lam], but here are a few examples of what you can do without
needing lambdas.

See the [operations overview][ops] in the offical language documentation,
or the [API reference material][api], for more details of these and other
useful functions.

### Statistics

If you have an array, list or set whose elements are of a numeric type,
then you can use the `min()`, `max()` to find the minimum and maximum of the
numbers in that collection.

You can also use the `sum()` and `average()` functions to compute the sum
and average (arithmetic mean) of those numbers.

### Element Ordering

Given an array or list, you can use the `reversed()` function to get a
new list with the elements in reverse order.

You can also use `sorted()` and `sortedDescending()` to get new lists whose
elements have been sorted into their natural ascending and descending order,
respectively.

The `shuffled()` function can be invoked on a list to get a new list in
which the elements have been reordered pseudo-randomly. If the list is
mutable and you prefer to reorder its elements in place, you can use
`shuffle()` instead

### Other Things

The `distinct()` function can be invoked on arrays and lists. It returns a
list in which duplicate values have been removed.

The `chunked()` function can be invoked on lists or sets to 'chunk' (i.e.,
group) their contents into a list of lists, each of a given maximum size.
