```{solution} ex-ifc-error
:label: sol-ifc-error
**Option 3 is correct.** The arrowhead should be an unfilled triangle.

Lines and arrows on a UML class diagram have specific meanings which vary,
depending on how you draw them. Implementing an interface is always shown
using a dashed line with an unfilled triangular arrowhead, pointing at
the interface.
```
