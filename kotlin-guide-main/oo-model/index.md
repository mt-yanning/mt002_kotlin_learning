# Object-Oriented Modelling

In this section, we take a short break from Kotlin and turn our attention to
the object-oriented development paradigm.

We start with a recap of [some essential object-oriented concepts][oo]
(what an object is, what a class is, etc). You can skim over this subsection
quickly if you understand these concepts fully, either from prior experience
or last year's coverage of them.

After that, we consider some [techniques for the determining which classes
are needed][tech] to fulfil the requirements of a software application.

We conclude the section with a look at the syntax for [UML class diagrams][uml]
and some different approaches to [drawing these diagrams][tools].
