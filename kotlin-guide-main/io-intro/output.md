# Console Output

You have already seen examples of using `println()` and `print()` for
console output in Kotlin. These functions both take a single argument, and
that argument can be of any type. If the argument is not itself a string,
a string representation of it will be generated, and this will then be
printed.

If you require more complicated output, you can combine fixed text with values
generated by your program using **string interpolation**, and then print this
string in the usual way.

A more flexible alternative to interpolation is to use the `format()`
extension function of the `String` class. The string returned by this function
can be printed in the usual way.

A third option, available on the JVM, is to call the `printf()` method of
`System.out`.

We consider each of these options below.

## Printing With String Interpolation

In Kotlin, you can interpolate (i.e., insert) a variable's value into a
string by including that variable's name in your string, prefixed by a `$`
symbol.

You can also interpolate the results of expression evaluation, property
access, function calls or method calls into a string. In these cases, you
need to enclose the expression, property access or call in braces, `{}`, as
well as using the `$` prefix.

Python has an equivalent feature, commonly known as the '[f-string][fstr]'.
C has no direct equivalent, but the same result can be achieved using the
`sscanf()` function.

Here are some examples of printing interpolated strings, with the equivalent
Python f-string syntax provided for comparison:

::::{tab-set}
:::{tab-item} Kotlin
```kotlin
print("Enter your name: ")
val name = readln()

println("Hello $name!")
println("Your name contains ${name.length} characters")
println("Is it a short name? ${name.length < 5}")
println("Uppercase name is ${name.uppercase()}")
```
:::
:::{tab-item} Python
```python
name = input("Enter your name: ")

print(f"Hello {name}!")
print(f"Your name contains {len(name)} characters")
print(f"Is it a short name? {len(name) < 5}")
print(f"Uppercase name is {name.upper()}")
```
:::
::::

## `format()` Function

String interpolation is much more basic in Kotlin than it is in Python. For
example, you can't interpolate a floating-point value with a specific number
of decimal places into a Kotlin string, whereas you can do that with a
Python f-string.

If you need more control of formatting in Kotlin, you can use the `format()`
extension function of the `String` class instead of interpolation. For example,
if you have a `Float` or `Double` variable named `distance`, representing a
distance in kilometres, you can format its value into a string and then print
that string with code like this:

```kotlin
println("Distance = %.2f km".format(distance))
```

Here, `%.2f` is a **format specifier** indicating that a floating-point
value should be inserted into the string at this point, and that it should
be formatted using two decimal places. The [available format specifiers][fmt]
are very similar to those used in C.

## `printf()`

A more direct approach to printing formatted output is to invoke the
`printf()` method on the special object `System.out`, which represents the
standard output stream associated with a program. Here's an example, with
the equivalent C code provided for comparison:

::::{tab-set}
:::{tab-item} Kotlin
```kotlin
val area = width * height
System.out.printf("Rectangle area is %.3f\n", area)
```
:::
:::{tab-item} C
```c
float area = width * height;
printf("Rectangle area is %.3f\n", area);
```
:::
::::

If you already know C, the nice thing about `System.out.printf()` is that it
allows you to carry on using a very familiar approach to outputting formatted
data on the console. However, repeated use of the `System.out` prefix quickly
becomes tedious and just adds clutter to the source code.

Fortunately, Kotlin provides a solution to this, via the `with()`
**scope function**:

```kotlin
with(System.out) {
    printf("Rectangle colour = (%d,%d,%d)\n", r, g, b)
    printf("Perimeter = %.3f\n", 2.0 * (width + height))
    printf("Area = %.3f\n", width * height)
}
```

Inside the braces, method calls are implicitly made on the subject of the
`with` call[^with]&mdash;in this case, the object `System.out`, which
represents the standard output stream. We say that `System.out` is the
**implicit receiver** of method calls inside the scope created by the braces.

We discuss scope functions in more detail [later][scp].

:::{note}
When you use `System.out.printf()`, you are bypassing Kotlin!

This method is part of the Java standard library. The clever thing about
Kotlin is that it integrates seamlessly with Java, allowing you to use
anything from the Java standard library, or third-party Java libraries, in
your Kotlin programs.

**Obviously, this is only true of software that is compiled for the JVM.**
If you target a different platform with the compiler then you won't be able
to use things like this in your code.
:::
