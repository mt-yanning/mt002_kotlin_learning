# Organizing Classes

Classes are not isolated entities. They are organized collectively in
specific ways to deliver the functionality of a software application. This
organization can take different forms.

We begin this section by considering the idea that closely-related classes
should be put into logical groups called [packages][pkg].

After that, we switch our attention to how classes are organized in relation
to each other. We start by comparing and contrasting the simple transient
[dependencies][dep] between classes with a stronger, more long-lived type of
relationship, termed [association][assoc].

We finish the section by considering two specialized and subtly different
kinds of association: [aggregation and composition][agg].
