# Task 9.6

Kotlin Toolchain project for an application that computes variance in a
numeric dataset.

See the Programming Guide for full details of this task.

## Linux & macOS

Run the unit tests for `variance()` with

    ./kotlin test

Run the application on a data file named `test.data` with

    ./kotlin run test.data

or

    ./run test.data

(The second of these runs the program with logging turned off.)

## Windows

If `cmd.exe` is your shell, omit the `./` from the commands shown above.

In Windows PowerShell, use `.\kotlin.bat` instead of `./kotlin`, and
`.\run.bat` instead of `./run`.
