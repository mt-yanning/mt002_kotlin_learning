# Portfolio: Week 4

## Relevant Preparation

This work draws on Sections 7 to 13 of the [Kotlin Programming Guide][guide],
and on your solution to a Week 3 portfolio task.

Everything in [Section 12][sec12] apart from Subsections 12.7 & 12.9 is of
particular relevance here. You will also find [Subsection 8.3][sec83] helpful.

## Instructions

There are *two* separate parts to this assignment - see the README files
in subdirectories `triangles` and `to-do-list` for full details.

In each part, you will be implementing Kotlin classes. Tests are provided
for you to verify the correctness of your implementations. **All the tests
must pass for you to achieve a grade of Pass on this assignment!**

You can run the main tests for both parts with

    ./kotlin test

Note that these tests will only work once you have written code for both
parts that compiles successfully.

There is one additional test for the `to-do-list` task, which you can
run on Linux or macOS using

    python check.py

(You may need to use `python3` instead of `python`, depending on where you
are doing this and how Python has been installed on that system.)
